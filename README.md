# AccessCheck Lite

Free, client-side HTML accessibility checker. **An Open Heightz initiative founded by Clesh TN Maluleka.**

## Use
Download or clone this repo and open `index.html` in a browser. Paste HTML in the box and click **Check HTML**. No network connection or sign-in required.

Checks include missing image alt text, unnamed buttons, missing page language, missing page title, and form inputs without labels. This is a *starter aid*, **not** a WCAG compliance certification or substitute for manual and assistive-technology testing.
